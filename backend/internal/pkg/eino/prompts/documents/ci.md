Generate a PROFESSIONAL COMMERCIAL INVOICE (CI) with the following structure.

CI STRUCTURE:
1. HEADER: "COMMERCIAL INVOICE" centered, bold 16pt. CI Number right-aligned. Reference PI Number.
2. SELLER/BUYER: Same two-column layout as PI
3. SHIPPING DETAILS:
   - Vessel/Flight: name and voyage number
   - Port of Loading / Port of Discharge
   - Bill of Lading / AWB Number
   - Date of Shipment (YYYY-MM-DD)
4. ITEMS TABLE: Same structure as PI but with actual shipped quantities
5. FINANCIAL SUMMARY:
   - Subtotal, Freight Charges, Insurance, Other Charges
   - GRAND TOTAL (bold)
6. DECLARATION: "We hereby certify that this invoice is true and correct and relates to goods of [Country of Origin] origin."
7. SIGNATURE BLOCK: Same two-column layout as PI
